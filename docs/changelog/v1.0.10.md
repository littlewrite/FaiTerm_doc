# `v1.0.10` (2026-11-02)

## Features

- Added WSL support for Windows local terminals. Choose a distribution, shell, and working directory, or leave the shell and directory blank to use the distribution defaults and start in its home directory. Windows files dragged into a WSL terminal are converted to their Linux paths automatically.
- Added a Shell Integration setting. When enabled, new tabs start in the current directory, command status and Git branches are detected, and file paths in terminal output can be opened directly. When disabled, your shell starts exactly as configured.
- Local terminals now follow the system working directory even with tmux or a custom shell, so new tabs and completion keep up with `cd`. File paths can be opened with a modifier-click; the default is ⌘ on macOS and Ctrl elsewhere, and the modifier is configurable.
- Files copied in Windows Explorer or a Linux file manager can now be pasted into the terminal as paths. Paths containing spaces are quoted automatically.
- Notebooks now support new code snippets, and notes, folders, and host groups can be named inline without leaving empty nodes behind.

## Improvements

- Menus now size themselves to their content, with consistent spacing, selection states, and checkmark placement across overflow menus, dropdowns, and context menus.
- Inactive terminal splits are dimmed according to their own theme, preserving clear focus in light, dark, and colorful palettes.
- Copy and paste now use the system clipboard consistently on Windows and Linux. On Windows, Ctrl+C copies selected text and still interrupts the running command when nothing is selected.
- Terminal notifications are rate-limited to avoid bursts. Mobile now reports only notifications sent by programs instead of inferring task completion from the terminal title.
- Host forms, password fields, and reveal buttons now behave consistently across desktop and mobile, and validation messages no longer change field height.
- AI messages show a timestamp, with copy and edit actions beside the bubble. The terminal status bar can be toggled from Settings or the Command Palette.

## Fixes

- Fixed missing hover and pressed feedback in menus, undersized context-menu highlights, and misaligned menu titles and descriptions.
- Fixed horizontal overflow in narrow lists, inline renaming or folder creation while searching notebooks, and empty host groups being created before they were named.
- Fixed a possible crash when changing the active terminal split and relative paths opening the wrong file after the terminal directory changed.
- Fixed Paste sending Ctrl+V to Windows and Linux terminals when the clipboard was empty or contained only an image.
- Fixed incorrect macOS behavior for some key combinations such as Option + letter, and an unnecessary confirmation prompt when closing a window with no tabs.
