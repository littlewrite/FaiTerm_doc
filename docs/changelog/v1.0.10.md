# `v1.0.10` (2026-11-02)

## Features

- Windows local terminals can now run Linux: open a WSL environment as a terminal, start in your home folder, and drag files in without worrying about paths.
- New tabs stay in the folder you are working in. The app recognises the commands you run and the branch you are on, and file paths in the output open with one click. Prefer your own setup? Switch it off and your shell starts unchanged.
- Hover a file path in the output and hold ⌘ or Ctrl to open it in your system's default app; the key can be changed in Settings.
- Copy files in Explorer or your file manager and paste them into the terminal — paths containing spaces are quoted automatically.
- Create snippets from the notebook menu, and name new notes, folders and host groups right where they appear.

## Improvements

- Menus now fit their content, with consistent spacing, highlighting and checkmarks.
- In split view, the pane you are typing in stands out and the others dim to match your theme.
- Copy and paste follow your system on Windows and Linux, so the usual shortcuts work as expected.
- Notifications arrive with more breathing room, and on mobile only messages from your programs are shown.
- Password fields, show buttons and form messages now look and behave the same on desktop and mobile.
- AI replies show when they were sent, with copy and edit beside them; the terminal status bar can be switched on from Settings.

## Fixes

- Menus respond properly to hover and press, with highlights that cover the whole row.
- Narrow lists no longer overflow, and notebooks can be renamed or extended while searching.
- Switching split panes is stable, and relative paths in older output open the right file.
- Paste no longer sends a stray keystroke when the clipboard is empty or holds only an image.
- Some key combinations on macOS behave correctly again, and closing a window with no tabs no longer asks for confirmation.
