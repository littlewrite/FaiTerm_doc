# `v1.0.11` (2026-11-24)

## Features

- Quick Connect: connect to a host once without saving it. If you want to keep it, save it as a host with one click.
- Batch Run: run the same command on several hosts and review each result separately, without one failure affecting the others.
- Session recording: record a terminal session at any time, then search and replay it with pause and speed controls.
- Broadcast input: type once and send the same input to terminals in a split view or to all connected terminal tabs.
- Host tags: add tags to hosts and filter your list by them.
- Mobile host folders: create, rename, and delete folders in the host list, and expand each one to see the hosts inside.
- More flexible connections: port knocking and several jump host sign-in options, with easier multi-hop setups.
- Sync now covers more: appearance, terminal, shortcuts, AI settings, and syntax highlighting across your devices.
- Sync conflicts can be resolved item by item, keeping the value from this device or another one.
- The desktop side panel brings AI, monitoring, processes, files, and logs into one place. A new Files panel follows the terminal's current folder.
- Mobile workspaces now have a tab strip for switching and closing tabs. Importing and exporting hosts and port forwarding also have mobile pages.

## Improvements

- Redesigned host monitoring with live, average, and peak values plus more metrics, and a clear notice when data is out of date.
- Command history now shows duration, an exit status, and a failure filter.
- The terminal sessions panel shows how many panes a workspace has, with each split pane listed separately.
- The desktop title bar and side panels share one layout, and forms and dialogs fit narrow windows better.
- The port forwarding dialog is easier to follow, with a clear explanation for each mode.
- The AI assistant panel is smoother while resizing the window or typing, with clearer tool cards and approvals.
- The welcome, about, and settings pages share a consistent style; About is now split into Version & Updates and Community & Feedback.
- Mobile pages share consistent headers and icon sizes, making file management and editing feel more unified.
- The AI `@` menu shows the right icon for each connection type, so local, WSL, SSH, Telnet, and serial terminals are easier to tell apart.

## Fixes

- WSL terminals no longer close right after opening when the host setup is incomplete.
- Terminal start failures now show a clear hint about what to check instead of a cryptic error.
- Background note saving and searching no longer risk closing the app when something fails.
- Some restored terminals no longer exit silently when the app is launched from Finder.
- Clicking a WSL folder label now opens the distribution's home folder instead of its root.
- The tab bar no longer bounces when the window is shown again.
- Stopping the AI assistant now stops the running command and prevents queued commands from being sent; timed-out AI commands no longer block later ones.
- The side panel no longer shows the previous host's tools after switching to a notebook or file tab.
- Host monitoring no longer stays stuck on refreshing in some environments.
- Fixed command history sorting in narrow windows and AI chats overwriting a terminal you just selected.
- Mobile host edits no longer overwrite changes received from sync, and deleted tags no longer stay in the filter bar.
