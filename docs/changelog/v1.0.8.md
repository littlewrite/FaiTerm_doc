# `v1.0.8` (2026-09-25)

> **Upgrade note**: The host data storage layout changed in this release, and hosts and groups saved by older versions are not migrated. Back up any important data before upgrading.

## Features

- Added an AI assistant with two modes — "Ask" for Q&A and "Agent" for tasks; Agent can bind to a terminal and run commands automatically. Supports OpenAI, Anthropic, Gemini, DeepSeek, Kimi, Qwen, GLM, MiniMax, Ollama, and any OpenAI-compatible endpoint.
- AI safety controls: dangerous commands require confirmation or are blocked outright, with a configurable per-task execution limit; the terminal command blacklist also applies to AI.
- AI chat history supports search, detail view, export, and re-running a conversation; added knowledge base retrieval and support for local MCP tools.
- Added Telnet, FTP, and Serial connection types: Telnet supports terminal type and line-ending settings; FTP supports directory browsing, upload, download, delete, rename, and new folders; Serial supports baud rate, data bits, stop bits, parity, and flow control.
- Hosts and servers are now a single connection list, with SSH, SFTP, Telnet, FTP, and Serial grouped, searchable, sortable, and icon-managed in one place.
- Paste a connection string on the host edit page to auto-detect the protocol and fill in the fields, such as `ssh://`, `sftp://`, `ssh user@host`, or a serial device path.
- Added terminal text highlighting with built-in rules and custom JSON rules, plus a live preview in settings.
- Added VSCode 2026, VSCode Modern, VSCode Classic, VSCode Plus, Solarized, and Forest themes; the default theme is now VSCode Modern.
- Added an "Enable interface animations" toggle.
- Added "Restore last workspace on startup" (on by default), restoring terminal, notebook, and file editor tabs plus the split layout; closing the app now offers to save the current state.
- Added "Switch to English input method when entering FaiTerm", restoring the previous input method on exit (Windows and macOS).
- File transfer progress now shows in the macOS Dock and Windows taskbar, merges multiple transfers, and alerts you when a transfer finishes or fails in the background.
- Added voice input on mobile, inserting the recognized text at the cursor.
- The mobile workspace is now "quick actions + recent activity", with one-tap entries for a local terminal, a new note, and a new chat.
- The left panel on desktop can be collapsed and restored from the top bar.
- Host tools (processes / services / Docker / scheduled tasks) now work on local Windows terminals.
- The desktop code editor's find bar jumps to the next match with Enter.

## Improvements

- The mobile AI chat input area and its settings share a unified capsule style; attachments open a source picker, and selecting beyond the limit is rejected in one go with an explanation.
- Removed the mobile "Ask / Agent mode" selector — the mode now follows whether a terminal context is selected, so mode and context no longer conflict.
- Mobile chat history moved to a left drawer, grouped by today / past week / earlier, with long-press to delete; it stays pinned as a left column on tablets.
- Settings restructured: desktop uses left-hand category navigation, with highlight, notifications, and quick commands becoming their own pages; mobile is reordered and regrouped, width-capped and centered on tablets, with list → edit becoming a side-by-side layout.
- Desktop dividers consolidated into three kinds — section boundaries, header underlines, and list row separators — so they no longer appear and disappear inconsistently.
- Reworked the mobile "drag from the screen edge to switch tabs" gesture and added a preview of the target tab.
- Improved tab title hover display and reduced redraw and rebuild overhead in high-frequency areas such as the terminal and monitor panel.
- Improved command completion: fixed path joining and separator detection (Windows vs. Unix), and streamed history and dynamic candidates in frames instead of waiting for everything to finish.
- Improved connection failure, file operation failure, and terminal disconnect messages with readable wording, distinguishing "reconnecting", "session ended", and "connection failed".
- Host tools panel output is condensed to a one-line summary, with the full output written only to the log.
- The welcome page is now "quick actions + recent hosts" with a browse-hosts entry.
- Fixed terminal rendering errors when a theme category is unavailable, resetting terminal settings clearing highlight settings, the code editor cursor still blinking after switching to the background, unexpected behavior when no AI provider is configured, the view not resizing after a Windows window resize, and several strings that were not localized.
