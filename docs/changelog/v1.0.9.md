# `v1.0.9` (2026-10-22)

## Features

- Added terminal splits. Right-click a terminal pane to split it left/right or top/bottom, create nested layouts, and use the current connection or another host in the new pane.
- Redesigned the desktop Command Palette. Quickly find and run commands, open hosts, insert snippets, or switch terminal themes, with recent items kept close at hand.
- Expanded the terminal theme collection to more than 600 palettes organized into families. Each family has paired light and dark variants, with search and curated/all views.
- Added terminal notifications. Notifications sent by programs can appear directly, completed AI tasks are reported, and terminal progress is reflected in the session list.
- Terminal URLs can now be opened directly, and file links can be opened with the system default app. Hovering over a link reveals its full target.
- Added an expandable mobile keyboard panel with customizable key groups, Ctrl/Alt modifiers, multiline sending, command history, quick commands, and passwords from the vault.
- Host Tools now include Disks and Logs, with more complete actions for processes, Docker, services, scheduled tasks, and ports. Mobile now has a full-page Host Tools view.
- The AI composer now supports note and context mentions, slash commands, context usage details, conversation compaction, available-tool inspection, and queued follow-up messages.
- Improved shell integration for zsh, fish, Nushell, PowerShell, and others, with more reliable working-directory, command-state, and Git-context detection.
- Remote filenames containing unusual bytes are no longer rendered as garbled text and can still be opened, downloaded, renamed, and deleted.

## Improvements

- SSH, SFTP, and Host Tools can now share one underlying connection. A failure in an individual channel no longer tears down the terminal that is using the same host.
- AI streaming uses fewer full-page redraws and no longer pulls the view back to the bottom while reading earlier messages. Long conversations can continue with context compaction.
- Redesigned mobile monitoring into separate CPU, memory, swap, and network cards with expandable trends.
- Unified the headers and in-place refresh state across the mobile file manager, preview, editor, and monitoring pages.
- Made the first mobile Host Tools load more reliable and condensed command output in panels to a summary, with full output written only to logs.
- Standardized desktop controls, colors, dividers, and status styles, including improved sidebars, tabs, context menus, and settings layouts in narrow windows.
- Unified unsaved-state handling and save actions across settings, with side-by-side list and editor layouts on tablets.
- Reduced redraw overhead in long lists, sidebars, tabs, and terminal panes, and reduced unnecessary rebuilds in background tabs.
- Improved startup initialization to reduce white-screen time on Android when returning to the app or showing permission prompts.

## Fixes

- An invalid terminal theme now falls back to the default instead of breaking the terminal or theme preview.
- Resetting terminal settings no longer clears text-highlight settings.
- Fixed shortcut hints that appeared in the opposite order from the actual shortcut.
- Fixed menus opening in the top-left corner after the right-side panel was collapsed.
- Fixed the code editor continuing to refresh its cursor while in the background.
- Fixed invalid AI chat state when opening a conversation or sending a message without a configured provider.
- Fixed cleared terminal rows still being treated as clickable links.
- Fixed the close button on mobile file managers and previews exiting the entire workspace.
- Fixed the UI not resizing after a Windows window was resized or maximized.
- Fixed several interface strings that did not follow the selected app language.
