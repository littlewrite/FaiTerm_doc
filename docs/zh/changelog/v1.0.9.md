# `v1.0.9` (2026-10-22)

## 功能

- 新增终端分屏：在终端面板上右键即可左右或上下拆分，也可以嵌套分屏，并为新面板选择当前连接或其他主机。
- 重新设计桌面端命令面板：可快速搜索和执行命令、打开主机、插入快捷命令片段或切换终端主题，并保留最近使用记录。
- 终端配色扩充到 600 多套，并按「族」组织：同一族提供浅色与深色方案，跟随应用明暗自动切换，支持搜索和「精选 / 全部」视图。
- 新增终端通知：程序通过终端发送的提醒可以直接弹出，AI 任务完成时也会通知；终端任务显示进度时，会话列表会同步显示状态。
- 终端中的网址可以直接点击打开，文件链接可交给系统默认程序处理；悬停时会显示完整目标。
- 移动端新增可展开的键盘面板：按键分组可以自定义，支持 Ctrl / Alt、整段文本发送、命令历史、快捷命令和从密钥库选择密码。
- 主机工具新增「磁盘」和「日志」页签，并完善进程、Docker、服务、计划任务和端口操作；移动端新增整页主机工具。
- AI 输入框支持提及笔记与上下文、快捷命令、查看上下文用量、压缩对话、查看可用工具，以及在一轮任务结束后继续发送消息。
- 完善 zsh、fish、Nushell、PowerShell 等 Shell 集成，提升本地和远程终端对工作目录、命令执行状态及 Git 上下文的识别。
- 远端文件名包含异常字节时不再显示成乱码，仍可正常打开、下载、重命名和删除。

## 优化

- SSH、SFTP 和主机工具现在可以复用同一条底层连接；单独通道发生异常时，不再因此断开正在使用的终端。
- AI 流式回复减少了整页重绘，查看较早消息时不会持续被拉回底部；长对话可以使用上下文压缩继续交流。
- 移动端监控页重新设计：CPU、内存、交换空间和网络速率分卡片展示，并可展开查看趋势。
- 移动端文件管理、预览、编辑和监控页统一顶部样式，刷新操作会在原位置显示进度。
- 主机工具在移动端首次打开更稳定，面板中的命令输出改为摘要显示，完整内容仅写入日志。
- 桌面端统一控件、配色、分隔线和状态样式，改善侧栏、标签栏、右键菜单及设置页在窄窗口下的布局。
- 设置页统一未保存状态和保存操作，平板上的列表与编辑区域可并排显示。
- 降低长列表、侧栏、标签栏和终端面板的重绘开销，并减少后台标签页的无效刷新。
- 改善启动时的初始化顺序，减少 Android 上返回应用或权限提示造成的白屏时间。

## 修复

- 终端主题配置失效时回退到默认主题，不再导致终端或主题预览报错。
- 重置终端设置不再连带清空文本高亮设置。
- 修复菜单中的快捷键提示与实际快捷键显示相反的问题。
- 修复右侧面板收起后，菜单可能弹到窗口左上角的问题。
- 修复代码编辑器切到后台后仍反复刷新光标的问题。
- 修复未配置 AI 服务商时打开 AI 对话或发送消息产生的异常状态。
- 修复终端清行后，空白区域仍被识别为可点击链接的问题。
- 修复移动端文件管理器和预览页的关闭按钮会退出整个工作区的问题。
- 修复 Windows 窗口缩放或最大化后界面尺寸不跟随的问题。
- 修复部分界面文案未跟随应用语言切换的问题。
