# `v1.0.8` (2026-09-25)

> **升级注意**：本次主机数据存储结构有调整，不会迁移旧版本保存的主机与分组数据。如有重要数据，请升级前自行备份。

## 功能

- 新增 AI 助手，支持「Ask 问答」与「Agent 任务」两种模式，Agent 可绑定终端自动执行命令；支持 OpenAI、Anthropic、Gemini、DeepSeek、Kimi、Qwen、GLM、MiniMax、Ollama 及任意 OpenAI 兼容端点。
- AI 安全管控：危险命令需确认或直接拦截，可限制单次任务的执行次数；终端设置里的「命令黑名单」对 AI 同样生效。
- AI 会话历史支持搜索、查看详情、导出与重新发起；新增知识库检索，并支持接入本地 MCP 工具扩展能力。
- 新增 Telnet、FTP、串口三种连接类型：Telnet 支持终端类型与换行格式；FTP 支持目录浏览、上传、下载、删除、重命名与新建目录；串口支持波特率、数据位、停止位、校验位与流控配置。
- 主机与服务器统一为一份连接列表，SSH、SFTP、Telnet、FTP、串口在同一列表中分组、搜索、排序与图标管理。
- 主机编辑页支持粘贴连接命令自动识别协议并填充字段，例如 `ssh://`、`sftp://`、`ssh user@host` 或串口设备路径。
- 新增终端文本高亮，内置规则并支持自定义 JSON 规则，设置页提供实时预览。
- 新增 VSCode 2026、VSCode Modern、VSCode 经典、VSCode Plus、Solarized、Forest 等主题，默认主题改为 VSCode Modern。
- 新增「启用界面动画」开关。
- 新增「启动时恢复上次工作区」（默认开启），可恢复终端、笔记本、文件编辑器标签与分屏布局；关闭应用时可选择保存当前状态。
- 新增「进入 FaiTerm 时切换为英文输入法」，离开应用后自动恢复（支持 Windows 与 macOS）。
- 文件传输进度可显示在 macOS Dock 与 Windows 任务栏，多个任务合并展示，后台完成或失败会提醒。
- 移动端新增语音输入，识别结果插入到光标处。
- 移动端工作区改为「快捷操作 + 最近进行中」，提供本机终端、新建笔记、新建对话三个一键入口。
- 桌面端左侧面板可收起，收起后可从顶栏再次展开。
- 主机工具（进程 / 服务 / Docker / 计划任务）支持 Windows 本机终端。
- 桌面端代码编辑器查找栏支持回车跳转下一个匹配。

## 优化

- 移动端 AI 对话的输入区与相关设置项统一为胶囊样式，附件来源改为弹出选择，超出上限整批拒绝并说明原因。
- 移动端取消「Ask / Agent 模式选择」，改为由是否选择终端上下文决定，不再出现模式与上下文互相打架的情况。
- 移动端会话历史改为左侧抽屉，按今天 / 最近一周 / 更早分组，长按可删除；平板端常驻左栏。
- 设置界面重构：桌面端改为左侧导航分栏布局，高亮、通知、快捷命令等拆分为独立页面；移动端重新排序分组，平板端限宽居中，「列表 → 编辑」改为左右分栏。
- 桌面端分隔线收敛为区域边界、标题栏下沿、列表行分隔三类，避免时有时无。
- 移动端「从屏幕边缘拖拽切换标签页」交互重做，并新增目标标签页预览。
- 优化标签标题悬停显示，并降低终端、监控面板等高频区域的绘制与重建开销。
- 命令补全优化：修正路径拼接与分隔符判断（区分 Windows 与 Unix），历史与动态候选分帧推送，不再等全部算完才显示。
- 优化连接失败、文件操作失败与终端断线提示，改为可读文案，并区分「正在重连 / 会话已结束 / 连接失败」三种状态。
- 主机工具面板的命令输出精简为单行摘要，完整输出只写入日志。
- 欢迎页改为「快捷操作 + 最近主机」，并提供浏览主机入口。
- 修复终端主题分类失效导致渲染报错、重置终端设置误清高亮设置、代码编辑器转入后台后光标仍闪烁、未配置 AI 服务商时的异常行为、Windows 窗口缩放后视图尺寸不跟随，以及多处文案未国际化等问题。
