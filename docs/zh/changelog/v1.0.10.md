# `v1.0.10` (2026-11-02)

## 功能

- Windows 本地终端新增 WSL 支持：可选择发行版、Shell 和工作目录，也可以留空直接使用发行版默认 Shell 并进入家目录。Windows 文件拖入 WSL 终端时会自动转换为对应的 Linux 路径。
- 终端设置新增「Shell 集成」开关。开启后，新标签从当前目录开始，可识别命令状态与 Git 分支，并能直接打开输出中的文件路径；关闭后则完全按你的 Shell 配置启动。
- 本地终端会跟随系统的当前目录，即使使用 tmux 或自定义 Shell，新标签和补全也能跟着 `cd` 走。文件路径支持按住修饰键点击打开，默认 macOS 使用 ⌘、其他平台使用 Ctrl，可在设置中修改。
- 在 Windows 资源管理器或 Linux 文件管理器中复制文件后，可直接在终端粘贴文件路径；含空格的路径会自动加引号。
- 笔记本支持新建代码片段，笔记、文件夹和主机分组均可直接在树或列表中命名。

## 优化

- 菜单宽度改为按内容自适应，并统一「+」菜单、下拉框和右键菜单的间距、选中状态与勾选布局。
- 终端分屏中未激活的格子会按当前主题自动压暗，浅色、深色与彩色配色下都保持清晰的主次层级。
- 改进 Windows 和 Linux 的复制粘贴行为，统一使用系统剪贴板；Windows 的 Ctrl+C 在选中文本时复制，未选中时仍可中断当前命令。
- 终端通知增加了频率限制，避免连续打扰；移动端也只显示程序主动发出的提醒，不再根据标题猜测任务完成。
- 主机表单、密码输入和显示/隐藏按钮在桌面端与移动端保持一致，错误提示也不再改变输入框高度。
- AI 对话的每条消息显示时间，复制与编辑操作移到气泡旁，查看历史更清爽；终端状态栏可直接从设置或命令面板切换。

## 修复

- 修复菜单悬停与按下反馈缺失、右键菜单高亮范围过小，以及部分菜单文字和说明错位的问题。
- 修复窄面板列表横向溢出、笔记本搜索状态下无法重命名或新建，以及主机分组先产生空节点的问题。
- 修复切换终端分屏时输入建议浮层可能导致的崩溃，以及终端目录变化后旧输出中的相对路径打开错误位置的问题。
- 修复剪贴板为空或只有图片时，「粘贴」仍会向 Windows / Linux 终端发送 Ctrl+V 的问题。
- 修复 macOS 上部分组合键（例如 Option + 字母）行为异常，以及没有标签时关闭窗口仍弹出确认框的问题。
