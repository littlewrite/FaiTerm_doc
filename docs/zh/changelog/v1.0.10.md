# `v1.0.10` (2026-11-02)

## 功能

- Windows 本机终端现在可以直接运行 Linux：把 WSL 环境当作终端打开，从家目录开始，拖入文件也不用操心路径。
- 新标签会停在当前所在的文件夹。应用能认出你正在运行什么命令、在哪个分支上，输出里的文件路径点一下就能打开。更喜欢自己的配置？关掉后 Shell 完全按你的设置启动。
- 把鼠标移到输出里的文件路径上，按住 ⌘ 或 Ctrl 点击，就能用系统默认程序打开；用的键可以在设置里改。
- 在资源管理器或文件管理器里复制文件，直接在终端粘贴即可，带空格的路径会自动加引号。
- 在笔记本菜单里新建代码片段，笔记、文件夹和主机分组都能在出现的位置直接命名。

## 优化

- 菜单宽度跟着内容走，间距、悬停和勾选位置更统一。
- 分屏时正在输入的面板更突出，其他面板按主题变暗。
- 复制粘贴跟随系统，Windows 和 Linux 上的常用快捷键按预期工作。
- 通知之间留有间隔，不再连续弹出；移动端只显示程序主动发出的消息。
- 密码框、显示按钮和表单提示在桌面端与移动端表现一致。
- AI 回复显示发送时间，复制和编辑就在气泡旁边；终端状态栏可以在设置里打开。

## 修复

- 菜单的悬停和按下反馈恢复正常，高亮覆盖整行。
- 窄面板的列表不再横向溢出，笔记本在搜索时也能重命名或新建。
- 切换分屏更稳定，较早输出里的相对路径也能打开正确位置。
- 剪贴板为空或只有图片时，粘贴不再误发按键。
- macOS 上部分组合键行为恢复正常，没有标签时关闭窗口不再弹出确认。
