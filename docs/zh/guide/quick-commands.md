# 快捷命令与命令历史

## 快捷命令

快捷命令是一排放在终端上的按钮，用来省掉反复敲的固定操作。**同一份配置同时出现在桌面端终端工具栏和移动端终端的快捷命令栏**，两端不必各配一遍（设置 → 快捷命令）。

### 三种动作

| 动作类型 | 行为 |
| --- | --- |
| 执行命令 | 立即执行命令并发送回车 |
| 插入文本 | 只把文本插入终端输入区，不回车，适合需要再改一改的片段 |
| 发送按键 | 发送按键序列，用空格分隔，例如 `Ctrl+B D` |

每条快捷命令都有名称、动作类型与对应的内容；按键序列无法识别时会直接提示，不会静默失败。

### 常见用法

- 执行：`git status`、`docker ps`、`tail -f` 之类的固定命令
- 插入：一段常用但每次要改参数的模板
- 按键：tmux 的 `Ctrl+B D`、`Ctrl+B %` 这类前缀组合

## 命令历史

工具轨道里的「历史」集中保存你在终端执行过的命令。

- 支持搜索与分页，长历史也能快速翻找
- 可以刷新与清空筛选条件
- 记录保存在本地；`v1.0.9` 起改用新的存储结构，桌面端**首次迁移会自动导入原有的 SQLite 历史记录**，不需要手动搬

> 命令历史属于本地数据。设置里的「删除所有数据」会连同历史一起清除，操作不可撤销。

命令补全的候选里也会混入历史命令，并标注来源（「历史建议」），见 [命令补全](/zh/guide/suggestion)。
