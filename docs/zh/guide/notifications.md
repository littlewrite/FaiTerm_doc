# 通知

## 通知中心

工具轨道底部的铃铛是**通知中心**，集中展示应用内产生的事件，例如终端 Alert、命令完成提示与传输结果；没有内容时会明确显示为空。

## 通知设置

设置 → 通知 里有几个总开关：

| 开关 | 作用 |
| --- | --- |
| 终端 Alert 时发送通知 | 终端里出现 Alert（例如命令跑了很久、脚本主动提醒）时投递通知 |
| 抑止终端通知 | 关闭后不再投递终端 Alert 类通知（Toast / 通知中心 / 系统通知一并生效） |
| 前台抑止系统通知 | 应用在前台时不再弹出操作系统通知，避免打断正在看的界面 |

> 指令行里常见的 OSC 通知（例如某些 CLI 工具跑完弹提示）也走这条链路，所以关掉总开关会一起变安静。

## 传输提醒

文件上传下载完成或失败时：

- 应用在后台：macOS Dock 跳动 / Windows 任务栏闪烁
- 应用在桌面且开启系统通知：投递一条完成通知

传输相关的进度展示见 [文件传输与管理](/zh/guide/files)。

## 相关

- 桌面端与移动端都各自有通知设置页，开关含义一致
