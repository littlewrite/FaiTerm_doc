# 密钥与凭据

工具轨道里的「密钥」用来集中管理凭据：**密码、私钥、私钥口令**都可以存成一条凭据，然后在多台主机之间复用，不必把同一份私钥反复粘贴进每条连接。

## 为什么用凭据

主机连接支持两种填法：

- 直接在主机里填密码或私钥
- 改为**引用一条凭据**（主机编辑页里的「已关联凭据」）

当多台主机共用同一个跳板机账号、同一把密钥或同一个私钥口令时，用凭据只需要维护一份；改密码时也只改一处。

## 创建凭据

在工具轨道打开「密钥」，点「添加」：

| 区块 | 内容 |
| --- | --- |
| 基础信息 | 名称与备注，用来区分这条凭据的用途 |
| 凭据内容 | 密码、私钥（可选密钥长度）或私钥口令 |

创建完成后，在主机编辑页的「已关联凭据」里选中它即可。

> 凭据也可以给主机之外的功能复用（例如工作区连接），所以这里保存的是**凭据本身**，而不是某一条连接的副本。

## 加密存储

设置 → 通用 里可以给本地数据设置一个密码：

- 设置密码后，**SSH 连接信息、密钥等敏感数据都会加密存储**
- 清空密码则关闭加密，数据以明文保存
- 更改密码后建议重启应用，确保完全生效
- 密码丢失后数据无法恢复，请妥善保管

> 需要彻底清空时，设置里提供「删除所有数据」：会永久删除设置、SSH 连接、密钥、命令历史等全部应用数据，操作不可撤销。
