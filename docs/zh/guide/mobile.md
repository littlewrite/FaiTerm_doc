# 移动端

Android 端不是桌面端的缩水版：它有自己的工作区、终端交互和 AI 对话界面，配置与桌面端共用同一套（登录后可通过数据同步对齐）。

## 工作区

没有打开任何标签时，工作区是「快捷操作 + 最近进行中」：

- 顶部三个一键入口：**本机终端**、**新建笔记**、**新建对话**
- 下面按时间倒序列出最近连过的主机、最近改过的笔记、最近聊过的会话

「本机终端」是移动端工作区独有的入口 —— 平时要从主机列表里绕一圈新建本地连接，这里一键直达。

## 终端

- 顶部标签页可以直接左右切换；也可以在屏幕边缘拖拽来切换标签：拖拽时会有一块跟手形变的椭圆，拉过约三分之一屏宽进入阻尼区，松手完成切换，未达阈值则弹回
- 拖拽过程中顶部会浮出目标标签页的预览卡片
- 底部是终端快捷命令栏（与桌面端共用同一份快捷命令配置）和常用控制字符
- 外接键盘可用，按键重绑定编辑器仅在桌面端提供

## AI 对话

- 底部输入区是一个整块胶囊：文字在上，附件、审批模式、用量、语音与发送键都在框内
- 输入框上方的开关（模型、终端上下文、知识库、思考）同样是胶囊样式，横向排不下时可以左右滑动
- 回形针弹出附件的来源（相册 / 文件 / 相机），图片是**追加**而不是替换，超过上限会整批拒绝并说明原因
- 支持语音输入，识别结果插入光标处
- **没有单独的 Ask / Agent 模式选择**：选了终端上下文就是 Agent（可调工具），没选就是 Ask
- 会话历史在左侧抽屉里：顶部是新建对话与搜索，下面按今天 / 最近一周 / 更早分组，长按可删除

模式和上下文的细节见 [AI Agent](/zh/guide/ai)。

## 设置

移动端设置按「日常使用 / 连接的主机 / 账号与数据」分组，条目对照桌面端：通用、终端、主题、高亮、通知、快捷命令、主机列表、密钥、AI、个人、数据同步、关于。

在横屏平板上，主机列表、密钥与 AI 这几个页面会变成左右分栏（左列表、右编辑）；手机与竖屏平板保持整页跳转。设置页在平板上限宽居中，表单不会横跨整个屏幕。

## 文件与笔记

移动端同样内置文件管理（浏览本机与远端目录、上传下载、预览图片与文本）和笔记本，笔记会参与桌面端一致的知识库检索。
