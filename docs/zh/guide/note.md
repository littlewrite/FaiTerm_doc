
# 笔记本与知识库

## 笔记本

工具轨道第 4 项是笔记本：左侧是笔记目录树，右侧是编辑区，支持 Markdown 编辑与预览、新建笔记与目录、命令片段。

笔记可以随工作区标签页一起被「启动恢复上次工作区」还原。

## 知识库检索（RAG）

在 AI 对话里可以打开「知识库」开关，让 AI 在回答前先从你的笔记里检索相关上下文，这样回答会带上你自己的资料。

- 面向笔记本内容建立检索
- 可以为知识库**单独配置 embedding 模型**（设置 → AI）
- 检索到的内容会作为上下文随消息一起发送，并在对话里标明来源

> 知识库不可用时（例如未配置 embedding 模型），对话会明确提示，而不是静默地当作没有知识库。
