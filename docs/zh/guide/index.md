# 关于 FaiTerm

**FaiTerm（Future AI Terminal GUI）是一个面向开发与运维的一体化终端客户端：本地终端、SSH / SFTP / Telnet / FTP / 串口连接、双栏文件管理、命令补全、AI Agent 与知识库、主机工具与监控，全都收在同一个窗口里。支持 Windows、macOS、Linux 与 Android。**

## 功能总览

### 终端

- 本地终端：zsh、bash、fish、nushell 等，多标签页与左右 / 上下分屏
- 远程连接：SSH、SFTP、Telnet、FTP、串口（Serial）统一成一份主机列表，粘贴连接命令即可自动识别协议
- 600+ 常用命令补全：支持子命令、参数、路径与历史候选
- 终端文本高亮：内置规则，也可以写自定义 JSON 规则，改动即时预览
- 快捷命令：执行命令 / 插入文本 / 发送按键三种动作，桌面与移动端共用一份配置
- 命令历史、终端内搜索、终端内端口转发、tmux 工具条、字号缩放

### 文件

- SFTP 双栏文件管理（本地 ↔ 远端），目录树、排序、批量操作
- 拖拽上传 / 下载，传输队列与完成提醒（Dock / 任务栏同步显示进度）
- ZModem（sz / rz）：在终端里直接收发文件

### AI

- **Ask 问答**与 **Agent 任务**两种模式，Agent 可绑定一个已连接的终端自动执行命令
- 多服务商：OpenAI、Anthropic、Gemini、DeepSeek、Kimi、Qwen、GLM、MiniMax、Ollama，以及任意 OpenAI 兼容端点
- 安全管控：审批模式（每次确认 / 智能审批 / 完全自动）、高危命令硬拦截、单次任务执行上限、命令黑名单
- 会话历史：搜索、详情、导出、重新发起；只保存脱敏摘要
- 知识库检索（RAG）与本地 MCP 外部工具

### 主机工具与监控

- 进程、服务、Docker、tmux（会话 / 窗口 / 窗格）、计划任务、端口占用
- 资源监控：CPU、内存、磁盘、网络的实时曲线
- 工具与监控都跟随「当前终端」所在的主机

### 界面与个性化

- 四栏工作区，分栏宽度可拖拽，面板可收起
- 11 套应用主题，浅色 / 深色 / 跟随系统；亚克力半透明窗口
- 终端配色内置 600+ 套（按「族」选择，跟着应用明暗自动切换）
- 启动恢复上次工作区、命令面板、快捷键可自定义

### 数据与账号

- 密钥 / 凭据集中管理，可在多台主机之间复用
- 本地数据可加密存储（设置 → 通用 里设置密码）
- 登录账号后可同步主机、密钥与笔记，支持手动与自动触发

## 界面结构

| 区域 | 内容 |
| --- | --- |
| ① 工具轨道 | 终端工作区 / 主机 / 密钥 / 笔记本 / 历史 / 通知 / 设置 |
| ② 列表栏 | 当前轨道的内容（工作区、主机、笔记、历史…），宽度可拖拽 |
| ③ 工作区 | 终端、文件管理、笔记本、代码编辑器等标签页 |
| ④ 工具集合 | AI Agent、监控、进程、Docker、tmux、服务、计划任务、端口 |

底部工具条属于 ③ 工作区：路径、常用控制字符（^D ^L ^U）、tmux 状态与终端操作按钮都在这一行。

## 平台

- Windows / macOS / Linux 桌面端
- Android 移动端：连主机、跑终端、写笔记、和 AI 对话（含语音输入）

安装方式见 [安装使用](/zh/guide/installation)。
