
# AI Agent

AI 面板在 ④ 工具集合里（默认第一个 tab），快捷键 `⇧⌘K`。

![AI 对话](/images/screenshots/ai_light.png)

## 两种模式

### Ask 问答

最简单的模式：你问，AI 回答，不会触碰你的环境。适合查资料、读代码、解释命令。

### Agent 任务

Agent 模式需要先绑定一个**已连接的终端**。绑定之后，AI 会分析你的请求，并在你的环境里调用工具执行命令（执行结果会以卡片形式回显在对话里，可以逐条审批）。

> 没有选择终端上下文时就是 Ask，选了就是 Agent —— 模式和上下文只有一处事实，不会互相打架。

## 服务商与模型

设置 → AI 里增删服务商与模型，可以刷新模型列表并**测试连接**：

OpenAI · Anthropic · Gemini · DeepSeek · Kimi · Qwen · GLM · MiniMax · Ollama · 任意 OpenAI 兼容端点

对话区的模型下拉可以随时切换当前模型。

## 安全管控

### 审批模式

| 模式 | 行为 |
| --- | --- |
| 每次确认 | 每条命令都要你点一次 |
| 智能审批 | 只有命中内置只读白名单的命令自动放行，写操作与无法识别的命令都需要确认 |
| 完全自动 | 不再逐条确认，但**高危命令仍然硬拦截** |

### 其他约束

- 危险命令识别：命中高危规则直接拦截，完全自动模式也不放行
- 执行上限：可以限制单次任务的命令执行次数，避免 AI 失控刷屏
- 命令黑名单：终端设置里的黑名单对 AI 同样生效，命中即强制转为人工确认
- 工具执行通道：可选「后台 Shell」或「当前终端（PTY）」，后者能复用你已经登录的会话

## 上下文

给 AI 的上下文都是显式选择、可随时移除的：

- 附件：文本文件与图片
- 只读标签：把某个标签页的内容作为只读上下文（AI 不能改它）
- 知识库：从笔记本知识库里检索相关笔记（RAG）
- 终端：Agent 模式绑定的那台终端

## 会话历史

- 按标题搜索历史会话，查看详情、导出 Markdown、**重新发起**同一条会话
- 历史只保存**脱敏摘要**：原始命令输出与推理内容不落盘，导出前还能选择脱敏
- 每次运行完成后会自动生成会话标题

## MCP 外部工具

支持接入本地 stdio MCP 工具，把你自己写的工具交给 AI 调用（设置 → AI → 外部工具）。
