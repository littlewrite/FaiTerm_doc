## Ask 模式

最简单无影响的是 Ask 模式：你问，AI 回答你的问题，不会触碰你的环境。

## Agent 模式

Agent 模式需要先绑定一个已连接的终端。绑定之后，AI 在收到你的请求时会分析你的请求，并尝试在你的环境里执行命令，例如：
