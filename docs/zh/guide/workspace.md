# 界面与工作区

![工作区](/images/screenshots/home_light.png)

## 四栏工作区

| 区域 | 说明 |
| --- | --- |
| ① 工具轨道 | 终端工作区、主机、密钥、笔记本、历史，底部是通知与设置 |
| ② 列表栏 | 显示当前轨道的内容（工作区、主机、笔记、历史…）；宽度可拖拽，左上角按钮可整栏收起 / 展开 |
| ③ 工作区 | 标签页区域：终端、文件管理、笔记本、代码编辑器… |
| ④ 工具集合 | AI Agent、监控、进程、Docker、tmux、服务、计划任务、端口；顶部 tab 放不下时，右端 ⋯ 列出全部工具 |

## 工作区

- 一个工作区 = 一个连接目的地（本机，或某台主机）；在工作区列表里可以搜索与切换
- 每个工作区里可以开多个标签页，列表行会显示当前目录或所在分支

## 标签页

- `⌘N` 新建标签页，`⌘W` 关闭当前标签，`⌘1` … `⌘9` 按序号切换
- 终端标签页右键可「左右分屏 / 上下分屏」
- `⌘[` / `⌘]` 在分栏之间移动焦点，`⌘Esc` 回到工作区
- 标签标题过长时，悬停可看完整标题

## 命令面板

`⇧⌘P` 打开命令面板：搜索并执行应用内的命令（新建标签页、切换工具、打开设置…）。

## 启动与恢复

- 「启动时恢复上次工作区」默认开启：恢复终端、笔记本、编辑器标签与分屏布局
- 关闭应用时可以选择保存当前状态
- 相关开关在 设置 → 通用

## 界面动效

- 「启用界面动画」控制菜单与悬停反馈的动画；关闭后所有切换瞬时完成
- 文字被截断时，悬停会自动显示完整内容
