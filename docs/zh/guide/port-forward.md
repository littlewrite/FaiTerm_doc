# 端口转发

端口转发入口在**终端底部工具条**上，仅对 SSH 连接可用。它基于当前这条 SSH 会话建立隧道，不需要再开一个 `ssh -L` 窗口。

## 两种方向

### 本地转发

把远端端口暴露到本机：在本机监听，用 `localhost:<本地端口>` 访问远端服务。

```
本机连 localhost:本地端口  →  SSH 隧道  →  远端 host:port
```

典型用途：把服务器上的数据库、Web 面板、Redis 拉到本地直接访问。

### 远端转发

把本机端口暴露到服务器：在 SSH 服务器上监听，他人通过 `server_ip:端口` 访问你的本机服务。

```
他人连 server:端口  →  SSH 隧道  →  本机
```

典型用途：临时把本地调试中的服务给同事或回调地址访问。

## 需要填什么

| 区块 | 字段 |
| --- | --- |
| 本机监听 → 转发到远端 | 本机绑定地址、本机端口、远端主机、远端端口 |
| 服务器监听 → 转发到本机 | 服务器绑定地址、服务器端口、本机主机、本机端口 |

创建完成后，转发会跟随当前 SSH 会话存活；会话断开时隧道一并结束。

## 状态提示

- 终端尚未连接时，面板会提示「请等待终端连接完成，或先建立连接」，不会让你先填一堆参数才发现连不上
- 非 SSH 连接（Telnet、串口、本地终端等）会提示**仅支持 SSH**

> 绑定 `0.0.0.0` 会让端口对同网段的机器开放，只想本机访问时请绑定 `127.0.0.1`。
