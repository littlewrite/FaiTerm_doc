# 主机工具与监控

![主机工具](/images/screenshots/host_light.png)

工具集合（④ 区）里的工具都**跟随当前终端所在的主机**：切到哪台主机的终端，工具就查哪台主机。本地主机同样可用（Windows 本机的进程 / 服务 / Docker / 计划任务也支持）。

## 工具列表

| 工具 | 能做什么 |
| --- | --- |
| 进程 | 按 CPU / 内存 / PID 排序，查看占用与用户，结束 / 停止 / 继续进程，修改优先级 |
| 服务 | 查看服务状态与描述，启动 / 停止 / 重启，查看 journal 日志 |
| Docker | 容器 / 镜像列表，启动 / 停止 / 重启、删除、看日志、进容器 shell |
| tmux | 会话 → 窗口 → 窗格 三级树，附加、重命名、结束；新建会话 |
| 计划任务 | cron / systemd timer / Windows 计划任务，查看详情与来源 |
| 端口 | 监听端口与连接、协议、状态、占用进程，可筛选 |

每个工具面板顶部都有一条筛选行，右上角可以刷新；列表行右侧的 ⋯ 是上下文操作。

## 资源监控

监控面板给出当前主机的实时曲线与用量：

- CPU（含 用户 / 系统 / 空闲 明细）与负载
- 内存用量
- 磁盘分区用量、磁盘 IO 读写
- 网络收发速率
- 采样间隔可选 10s / 4s；曲线时间范围可在 1H 等档位间切换

## 使用提示

- 工具面板在右侧（④ 区）以 tab 形式存在，放不下时用右端 ⋯ 选择
- 连接断开或主机不可达时，面板会给出明确的状态提示，并在重连后自动刷新
- 输出内容较多时，面板只显示单行摘要，完整输出可以在日志里查看
