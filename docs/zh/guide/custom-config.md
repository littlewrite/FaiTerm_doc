# 个性化配置

这一页把「把它调成我习惯的样子」的入口收在一起，具体步骤都在各自的专题页里。

## 外观

- **应用主题**：11 套配色 + 浅色 / 深色 / 跟随系统 → [主题](/zh/guide/theme)
- **终端配色**：内置 600+ 套，按「族」组织，跟着应用明暗自动切换
- **背景图片**：铺满（保持比例）/ 拉伸（填充屏幕），可调蒙版不透明度
- **亚克力半透明窗口**：桌面端可开，默认关闭
- **终端字体**：字体、字号、行高与字符间距，字号也能用 `⌘=` / `⌘-` 临时改

## 交互

- **快捷键**：设置 → 快捷键，点一下按键区域再按新组合即可 → [快捷键](/zh/guide/shortcuts)
- **命令面板**：`⇧⌘P` 搜索并执行应用内命令
- **面板布局**：分栏宽度可拖拽、左右面板可收起 → [界面与工作区](/zh/guide/workspace)
- **界面动画**：关掉后菜单与悬停反馈瞬时完成
- **终端文本高亮**：内置规则 + 自定义 JSON 规则 → [终端高亮](/zh/guide/highlight)

## 终端行为

- **命令补全**：开关、手动请求建议的快捷键 → [命令补全](/zh/guide/suggestion)
- **快捷命令**：执行命令 / 插入文本 / 发送按键 → [快捷命令与命令历史](/zh/guide/quick-commands)
- **命令黑名单**：命中关键词的命令执行前需要确认（对 AI Agent 同样生效）
- **滚动速率**、光标与控制字符等：设置 → 终端

## 启动与数据

- **启动时恢复上次工作区**：设置 → 通用，默认开启
- **本地数据加密**：设置密码后加密保存连接信息与密钥 → [密钥与凭据](/zh/guide/secrets)
- **账号与数据同步**：在多台设备之间对齐主机、密钥与笔记 → [账号与数据同步](/zh/guide/sync)
