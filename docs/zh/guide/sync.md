# 账号与数据同步

设置 → 个人 里集中管理账号信息与云端同步。

## 账号

登录后即可查看同步状态并使用云端功能；未登录时同步相关的操作会提示需要先登录，而不是静默失败。这一页同时管理**已登录设备**：可以看到当前设备与其他设备的登录情况，并把它们全部登出。

## 同步范围

目前可同步的是：

- 主机（Hosts）
- 密钥（Secrets）
- 笔记

> 同步与「本机加密」是两件事：本地加密负责把数据在磁盘上加密保存，云端同步负责在多台设备之间对齐数据。详见 [密钥与凭据](/zh/guide/secrets)。

## 触发方式

同步可以在下面这些时机自动发生，也可以随时手动触发：

| 触发 | 说明 |
| --- | --- |
| 手动 | 点「立即同步」推一次 |
| 启动 | 应用启动时检查并同步 |
| 定时 | 周期性检查（默认 5 分钟一轮） |
| 编辑 | 修改数据后延迟合并，避免边改边传 |
| 关闭 | 退出应用前推一次 |

## 同步记录

「最近同步记录」会列出一条条同步活动及其来源（手动 / 启动 / 定时 / 编辑 / 关闭），并显示结果属于**下载**还是**合并**。记录可以一次性清空，清空操作不可恢复。

数据同步页同时给出几个基础状态：上次同步时间、已跟踪的同步类别、本地是否还有未同步的修改、云端校验值等。

> 如果长时间没有成功记录，先确认账号是否处于登录状态，再手动点一次「立即同步」看具体报错。
