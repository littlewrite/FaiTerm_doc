# 终端高亮

终端高亮是一层**绘制覆盖**：它只改变显示颜色，不会改动终端里保存的 ANSI 原文，所以复制出来的内容、`tmux` 里的真实颜色都不受影响。

## 内置规则

按 shell 语法识别命令、参数、路径、字符串等元素，并给它们上色。可以在 设置 → 语法高亮 里逐条开关，并调整颜色。

## 自定义规则（JSON）

内置规则之外，还可以写自己的 JSON 规则，例如给特定关键字、日志级别或 IP 上色：

```json
{
  "name": "log level",
  "pattern": "\\b(ERROR|WARN|INFO)\\b",
  "color": "#e5ba7d",
  "bold": true
}
```

规则支持：纯文本或正则匹配、前景色、加粗，以及「保留 ANSI 颜色」等开关。保存时会校验 JSON、正则与颜色格式。

## 实时预览

设置页里有一段用**当前终端主题 + 已启用规则**渲染的真实输出，改规则或改主题都能立刻看到效果。

## 开关联动

关闭「启用高亮」总开关后，解析语言、保留 ANSI 颜色、规则的新增 / 编辑 / 启停、JSON 编辑都会置灰，避免在关闭状态下改动无效配置。
