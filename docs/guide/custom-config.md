# Personalization

This page collects the main ways to make FaiTerm fit your workflow.

## Appearance

- Choose an [application theme](/guide/theme) or a terminal color family.
- Add a background image and adjust its overlay opacity.
- Enable the desktop acrylic effect.
- Change terminal font, size, line height, and character spacing.

## Interaction

- Rebind shortcuts in [Keyboard Shortcuts](/guide/shortcuts).
- Use `⇧⌘P` to run commands from the Command Palette.
- Resize or collapse the side panels in the [Workspace](/guide/workspace).
- Disable interface animations for instant transitions.
- Configure [terminal highlighting](/guide/highlight) with built-in or custom rules.

## Terminal behavior

- Configure [command completion](/guide/suggestion) and its shortcut.
- Create execute, insert-text, or send-key [quick commands](/guide/quick-commands).
- Add a command denylist; matching commands require confirmation, including commands proposed by AI Agent.
- Adjust scrolling, cursor, and control-character settings under **Settings → Terminal**.

## Startup and data

- Restore the previous workspace on startup under **Settings → General**.
- Encrypt local connection and key data with a local password in [Secrets](/guide/secrets).
- Keep hosts, secrets, and notes aligned across devices with [Account and Sync](/guide/sync).
